# embedded-learning

嵌入式学习主线仓库 · 起点 2026-11-04 (W1) · 目标 2028-03 简历成型

## 目录约定

| 目录 | 用途 |
| --- | --- |
| `week01/` | 第一周: 环境验证、C 语言常识自测 |
| `notes/` | 每周笔记、原理图、时序图、博客草稿 |
| `jd/` | 长沙/外地嵌入式 JD 截图与技能词频表 |
| `projects/` | 简历级项目 (项目①②③) |
| `contest/` | 2027 电赛备赛资料与代码 |
| `linux/` | 嵌入式 Linux: 启动链、设备树、Buildroot |
| `drivers/` | 字符设备、platform、I2C 子系统 |
| `direction/` | 方向深耕: CAN/J1939、运动控制、国产化平台 |
| `assets/` | 数据手册、Datasheet 摘录 |

## 三条铁律

1. 代码只放在 `~/embedded/`，**不要**放 `/mnt/c/` 或 `/mnt/d/`（跨文件系统编译慢且易出权限/换行符问题）。
2. 每天 4 块 x 50 分钟，每周 6 天 + 1 天休整。时间富余只加「同一项目第三遍」，不提前学下一模块。
3. 每周至少 1 次有意义的 commit + 1 篇笔记。「跑通了」不算达标，能讲清「为什么」才算。

`W##: <一句话说明>`  例如 `W07: add gpio bit-op macros without HAL`
